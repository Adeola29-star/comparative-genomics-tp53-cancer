## Overview

This folder documents the computational workflow used for the comparative genomics analysis of TP53.

The workflow involved:

1. Retrieval of TP53 protein sequences from public databases.
2. Multiple sequence alignment using Clustal Omega.
3. Generation of a pairwise percentage identity matrix.
4. Construction of a phylogenetic tree to examine evolutionary relationships.
5. Qualitative examination of conserved sequence patterns within the alignment.

## Current Status

The initial analysis was performed using bioinformatics web-based tools, including Clustal Omega.

Future versions of this project may include reproducible scripts for:
- sequence retrieval
- automated alignment
- phylogenetic analysis
- sequence conservation analysis

## Purpose

This folder is maintained to document the analytical workflow and support future reproducibility of the TP53 comparative genomics investigation.
